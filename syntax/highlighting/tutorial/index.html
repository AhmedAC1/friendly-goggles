Syntax highlighting tutorial

infoNOTE: This only works with elements that are uneditable.

Import Prism:

Theme (put in head)

<link
    rel="stylesheet"
    href="https://cdn.jsdelivr.net/npm/prismjs/themes/prism.css"
>

JS (put in body, important)

<script>
    src="https://cdn.jsdelivr.net/npm/prismjs/prism.js"
</script>

Use it:

<pre><code class="language-any">code here</code></pre>
